About BlogCraft Platform

A production-grade blogging platform built in Python Flask demonstrating modular MVC design, secure authentication, relational database management, and modern responsive UI.

Project Objectives

BlogCraft was conceived and engineered across an intensive 8-week software engineering curriculum. The platform solves the fundamental challenges of content management systems: secure multi-user credential storage, resilient relational data associations (one-to-many, many-to-many), sanitized rich-text authoring to mitigate XSS attacks, real-time community commenting, and flexible SQL query filtering.

Technology Stack

Backend & Database
  • • Python 3.13: Core programming language
  • • Flask 3.x: WSGI framework & application factory
  • • Flask-SQLAlchemy: ORM & relational data modeling
  • • SQLite: Embedded ACID-compliant database
  • • Flask-Migrate: Database schema migration management
Frontend & UX
  • • Bootstrap 5.3: Responsive grid & components
  • • Jinja2: Server-side template inheritance
  • • Bootstrap Icons: Modern UI vector iconography
  • • Quill Editor: WYSIWYG rich-text authoring
  • • Vanilla JS: Dynamic DOM & client-side interactions
Security & Defense
  • • Werkzeug Security: Salted PBKDF2 password hashing
  • • Flask-WTF: CSRF tokens on all state changes
  • • Bleach: HTML sanitization against XSS injections
  • • Flask-Login: Session management & access control
Quality Assurance
  • • Unittest / Pytest: Automated test suites
  • • In-memory SQLite: Isolated test environments
  • • Authorization checks: Owner-only update & delete verification

Weekly Engineering Milestones

Week 1
Flask Setup & Application Factory

Project initialization, configuration profiles (dev, test, prod), extensions initialization, and Jinja2 base templates.

Week 2
User Authentication & Sessions

Flask-Login integration, secure registration with email validation, login, protected routes, and author dashboards.

Week 3
Relational Database Models & CRUD

Post, Category, Tag models with M2M associations, Flask-WTF forms, full CRUD operations, Quill Rich Text editor, and Bleach HTML sanitization.

Week 4
Modern UI/UX & Responsive Views

Custom CSS design system, responsive navigation, blog cards, category views, author profiles, and 403/404/500 error pages.

Week 5
Commenting & Community Discussion

Relational Comment model, live commenting stream, deletion authorization for authors, and validation.

Week 6
Full-Text Search, Filtering & Pagination

Multi-column keyword search (title + body), category/tag filters, sort orders (newest, oldest, views), and pagination.

Week 7
Automated Testing & Deployment Readiness

Unit & integration tests covering auth, CRUD, comments, search, and security; requirements.txt, .env configuration, and seed automation.

Week 8
Internship Video Script & Evaluation Kit

Mentor presentation walkthrough script, screenshots checklist, architecture diagrams, and submission deliverables.
